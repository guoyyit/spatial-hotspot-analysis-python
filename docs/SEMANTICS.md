# 统计口径与参数语义

本服务在本机完成事件写入、持久化、热点识别与密度聚类，不依赖任何外部服务。
本文档明确数据口径、时间窗口语义、统计量定义与参数含义，保证历史结论可复现。

## 1. 事件身份与写入语义

- 事件字段：`event_id`（调用方提供的唯一标识）、`lon`、`lat`、`ts`（事件时间，POSIX 秒）。
- **去重**：以 `event_id` 为唯一键。重复提交只计一次；同一批内的重复也只计一次。
  重复事件保留**首次到达**时携带的坐标与时间戳，之后的重复提交不改变任何状态。
- **乱序/迟到**：按 `event_id` 去重、按事件时间 `ts` 归档统计，与写入顺序无关。
  同一组数据无论一次性写入、分批写入、乱序写入还是插入迟到事件，得到的统计结果一致。
- 每次有新事件提交，单调递增的 **version** 加 1；纯重复批次不推进 version。

## 2. 时间窗口与迟到事件

- 所有窗口都作用在**事件时间 `ts`** 上，与接口被调用的墙钟时间无关。
- 窗口统一为**半开区间 `[start, end)`**：包含 `start`，不包含 `end`。
  - `start` 缺省表示无下界，`end` 缺省表示无上界；`start == end` 为空窗口。
- 时间轴按固定宽度的时间桶切分（默认 3600 秒，`SPATIAL_BUCKET_WIDTH_S` 可配），
  桶以 POSIX 纪元为锚点，桶边界不随数据变化。
- **不存在水位线（watermark），历史窗口永不关闭**。迟到事件仍被接受，并被追溯计入
  其 `ts` 所在的历史时间桶。因此：
  - 对历史窗口的查询结果会在迟到事件提交后发生变化，这是预期行为；
  - 已缓存结果通过 `status` 字段标注：`current` / `stale_data`（有更新数据）/
    `stale_params`（参数已被新参数集取代）；
  - 需要最新结论时带 `refresh=true` 重新计算。

## 3. 空间建模

- 经纬度先通过以可配置原点（`SPATIAL_ORIGIN_LON/LAT`，默认 0,0）为锚点的
  **等距矩形投影**换算为平面米坐标 `(x, y)`，距离全部在平面米制下计算。
  原点附近投影二阶精确，适合城市级分析；建议把原点设到研究区域中心。
- 分析网格以投影原点为锚点，网格大小 `grid_size_m` 为**每次查询的参数**，
  不落库；因此调整网格大小无需迁移数据，网格索引也不随迟到事件扩展而漂移。

## 4. 热点识别（Getis-Ord Gi*）

- 在窗口范围内，把网格单元作为要素，要素属性为该单元内的事件计数。
- **研究区域**取所有非空单元的最小外接矩形（含其中的零计数单元，同样参与检验）。
- 邻域权重 `w_ij` 由核函数与带宽决定（距离在带宽外权重为 0）：
  - `binary`（默认）：`d <= bandwidth_m` 时为 1，否则为 0（含自身）；
  - `gaussian`：`exp(-(d/bw)^2/2)`，在 `d > bandwidth_m` 处截断为 0。
- 单元统计量采用标准 Gi* 形式：

  `z_i = (sum_j w_ij x_j - mean * W_i) / sqrt( (n*S1_i - W_i^2)/(n-1) * var )`

  其中 `x_j` 为单元事件数，`W_i = sum_j w_ij`，`S1_i = sum_j w_ij^2`，
  `n` 为研究区域单元数，`mean/var` 为全部单元计数的均值与方差。
  当区域只有一个单元或方差为 0 时 `z = 0`（不可检验）。
- `p_value_raw` 为标准正态双侧 p 值：`erfc(|z|/sqrt(2))`。
- `z > 0` 且修正后显著记为 `hotspot`，`z < 0` 且显著记为 `coldspot`，
  否则为 `nonsignificant`。

## 5. 显著性与多重比较修正

- `alpha`：显著性水平，默认 0.05，必须在 `(0, 1)`。结果按 **修正后 p 值 `< alpha`**
  判定显著，响应中同时给出 `p_value_raw` 与 `p_value_adj`。
- `correction`：
  - `none`：不修正，`p_value_adj = p_value_raw`；
  - `bonferroni`：`min(1, p * m)`，`m` 为检验单元数；
  - `fdr_bh`（默认）：Benjamini-Hochberg 逐步上升法，单调且与输入顺序无关。
- 响应里的 `correction` 字段明确标注本次实际使用的修正方式，历史结果可追溯。

## 6. 密度聚类（DBSCAN）

- 参数：`eps_m`（邻域半径，米，必须为正）、`min_samples`（含自身的成核最小点数，>=1）。
- 输入为窗口内事件的米制坐标；同一坐标上的多个事件**保留多重性**（密度信号）。
- 确定性保证：输入先按 `(x, y, 输入序号)` 稳定排序，簇编号按“首个成核点”顺序确定，
  同参数同数据多次运行结果逐次一致。噪声点标签为 `-1`，单独统计 `noise_count`。
- 输出每个簇的成员数、质心与外接矩形（换算回经纬度），按规模降序排列。

## 7. 增量更新、快照与全量重建

- 增量：写入事务同时更新原始事件与按时间桶的汇总表，二者在同一事务提交。
- 全量重建：从原始事件重算时间桶汇总到暂存表，在写锁与 version 校验下原子改名替换；
  重建期间读取要么看到旧表、要么看到新表，绝不会看到混合状态。
- 重建完成后自动比对全量与增量两种路径下的单元计数，必须完全一致，否则报错。
- 一致性快照：每次查询在单个 SQLite WAL 只读事务内完成，读取的是某一个已提交版本。
  响应中的 `version` 即该快照对应的数据版本，并发写入不阻塞读取。

## 8. 崩溃恢复与有界资源

- SQLite 运行在 WAL + `synchronous=FULL`，提交即落盘；未提交批次整体回滚，
  不会出现半更新；崩溃的重建暂存表在启动时自动清理。
- 已提交的事件与统计在重启后立即可查询；配置（原点、桶宽）持久化且不可被冲突配置覆盖。
- 有界内存：原始事件与桶汇总都在磁盘数据库中，引擎内存中只保留少量结果缓存；
  窗口扫描通过时间桶索引剪枝，代价随查询窗口而非全量历史增长。
